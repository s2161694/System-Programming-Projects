## 查询清单

### 关系代数查询 (5个)
1. ✅ 从未从自己分支借书的顾客
2. ✅ 总是按时归还的顾客

4. ✅ 每个库存分支都有可用副本的书籍
5. ✅ 多次借阅同一本书的顾客

### SQL查询 (5个)
1. ✅ 每本库存书的借阅次数和平均借阅时长
2. ✅ 每个顾客的活跃借阅、按时归还和逾期归还统计
3. ✅ 每个分支的书籍数量和顾客数量
4. ✅ 每个书籍类别的借阅者数量和副本数量
5. ✅ 总是在新借阅前归还所有旧借阅的顾客
