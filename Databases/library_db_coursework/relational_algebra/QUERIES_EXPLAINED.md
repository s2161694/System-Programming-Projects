# 关系代数查询说明

## Query 1: 从未从自己分支借书的顾客
**输出**: customer (顾客ID), branch (分支)
**说明**: 
- 顾客借过书，但从未从自己账户所在的分支借过
- 没借过任何书的顾客不在输出中
- 无重复

## Query 2: 总是按时归还的顾客
**输出**: cust_id (顾客ID), name (姓名)
**说明**:
- 所有借阅都按时归还（归还日期 ≤ 到期日期）
- 未归还的借阅算逾期（因为到期日期在过去）
- 没借过书的顾客不在输出中
- 无重复

## Query 3: 首位预约可以在本地完成的书籍
**输出**: title, author, cust_id (顾客ID), branch (分支)
**说明**:
- 至少有一个可用副本
- 队列号最小的预约是由顾客发起的
- 该顾客的账户在有该书可用副本的分支
- 没有预约的书不在输出中
- 每条记录只出现一次

## Query 4: 每个库存分支都有可用副本的书籍
**输出**: title, author, branch (分支)
**说明**:
- 对于每个有该书副本的分支，至少有一个副本可借
- 返回书和每个有可用副本的分支
- 每条记录只出现一次

## Query 5: 多次借阅同一本书的顾客
**输出**: customer (顾客ID), title, author, last_loan (最后借阅日期)
**说明**:
- 同一顾客借同一本书多于一次
- 返回最后一次借阅的开始日期
- customer, title, author组合唯一
